# Shareable Dashboard URLs Guide

This guide explains how to share direct links to specific sections of the Pulse Survey Dashboard with stakeholders.

## Available Sections

You can now share direct links to any of these dashboard sections:

### 1. Overview Dashboard
**URL:** `index.html`  
**Description:** Main dashboard showing key metrics, culture dimensions, and sentiment analysis

### 2. Reports Section  
**URL:** `reports.html`  
**Description:** Report generation interface with filters and customization options

### 3. Progress Tracker
**URL:** `progress.html`  
**Description:** Survey completion monitoring across organizational hierarchy

### 4. Survey Interface
**URL:** `survey/index.html`  
**Description:** Interactive survey form for respondents (opens in new window)

### 5. Comments Analysis
**URL:** `comments-analysis.html`  
**Description:** Advanced AI-powered sentiment analysis and comment insights

## How to Share Links

### Option 1: Copy from Browser
1. Navigate to the desired section by clicking the tab
2. Copy the URL from your browser's address bar
3. Share this URL with stakeholders

### Option 2: Construct URLs Manually
- For Overview: `https://yourdomain.com/index.html` (overview is the default main dashboard)
- For Reports: `https://yourdomain.com/reports.html`  
- For Progress: `https://yourdomain.com/progress.html`
- For Survey: `https://yourdomain.com/survey/index.html`
- For Comments Analysis: `https://yourdomain.com/comments-analysis.html`

## Features

✅ **Direct Access** - Links take users directly to the specific section  
✅ **Browser Navigation** - Back/forward buttons work correctly  
✅ **Bookmark-friendly** - URLs can be bookmarked and shared  
✅ **Mobile Compatible** - Works on all devices

## Important Notes

### Survey Link Behavior
- The **Survey** link now opens in a new window/tab instead of a popup
- This makes it easier to share and bookmark the survey directly
- Perfect for sending to respondents who need to complete the survey

### Survey Navigation Features
- **Back to Dashboard** button: Returns users to the main dashboard overview
- **Restart Survey** button: Clears all responses with confirmation prompt
- Smart navigation: Handles both popup and direct access scenarios

### Comments Analysis
- The clean URL `comments-analysis.html` automatically redirects to the latest version
- No need to remember version numbers - always get the most current features
- The redirect is seamless and immediate

## Note for Stakeholders

When you receive a shared link:
1. Click the link to open the dashboard
2. You'll be taken directly to the relevant section
3. Use the navigation tabs to explore other sections if needed
4. The URL will update as you navigate, making it easy to share your current view
5. Survey and Comments Analysis links open in separate windows for focused work

This makes it easy to reference specific parts of the dashboard in meetings, emails, or reports.
