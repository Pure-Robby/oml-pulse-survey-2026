What to Verify

  • Scale Type: Both report types should use the 5-point scale section
  • Colors: Header and theme colors should match the dimension
  • Content: All "Loading..." text should be replaced with actual data
  • Questions: Top/bottom scoring questions should populate automatically
  • Headers: Page headers should include the correct dimension name
  • Console: Check browser console for any errors

Sample Data

The reports use sample data that includes:

  • Employee headcount: 8,540
  • Response count: 4,750
  • Response rate: 56%
  • Various filter combinations and demographics
  • Realistic scoring data for each dimension

Troubleshooting

  • If content shows "Loading...":
    • Open browser console (F12) and check for JavaScript errors
    • Verify that config.js and data.js are loading (check Network tab)
    • Check console for debug messages from the report engine
  • If wrong scale shows: Verify URL parameter is detected correctly in console
  • If colors are wrong: Check CSS custom properties are being set in Elements tab
  • If config.js not found: System should fall back to built-in configuration
